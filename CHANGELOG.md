# Changelog

## 1.0.0 — 2026-08-10

### Added
- Initial release
- `NotificationType` — predefined notification types (info, warning, error, success, custom)
- `InAppNotificationModel` — in-app notification data model
- `InAppNotificationsNotifier` — in-app notifications state management (load, mark read, unread count)
- `MoeNotifyConfig` — configurable push/in-app settings
- `MoeNotify.setup()` — entry point
- Riverpod providers: `inAppNotificationsProvider`
